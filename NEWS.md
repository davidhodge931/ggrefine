# ggrefine (development)

* Renamed themes to avoid namespace collision.
* Added refine prefix to `classic_*`, `modern_*`, `void_*` and `minimal_*`, and requried `discrete` argument.   
* Added positional zero scale thin wrappers.
* Added blend scales and blend/contrast aesthetics.
* Added `legend_ticks_linetype = 0` argument.
* Added `refine_legend` function.
* Added `update_*` function for palettes and panel size.

# ggrefine 0.5.0

* Added `theme_ggplot2`.
* Added `lineend = "butt` to `axis.ticks` and `panel.grid`.
* Rewrite of refine API.
* Refactored code.

# ggrefine 0.4.0

* Removed `geom_*` and `palette_*` arguments.
* Minor legend changes.
* Updated Readme.

# ggrefine 0.3.0

* Renamed `fusion` to `hybrid`.
* Added `minimal`.
* Change panel grey in `theme_ggplot2` to `"grey92"`.
* Added `theme_oat` back in.
